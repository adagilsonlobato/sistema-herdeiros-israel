# Clube Herdeiros de Israel — protótipo visual

Este repositório contém apenas a interface de demonstração enviada originalmente. **Não há backend, banco de dados nem login funcional.** Não use para cadastrar informações pessoais.

Para visualizar a interface pelo GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

A publicação completa requer backend com autenticação segura, PostgreSQL, configuração de hospedagem e revisão de segurança antes de usar dados de menores.
